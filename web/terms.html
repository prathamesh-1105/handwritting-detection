3. Algorithmic Nature and Accuracy Disclaimer

The underlying model is a sequential recurrent neural network composed of 128 LSTM units, Dropout, and Dense projection layers, evaluated strictly on 47 balanced alphanumeric classes from EMNIST:

  • Empirical Accuracy: The measured overall test accuracy is 86.53% with a Macro F1-score of 86.44% across 18,800 held-out test samples.
  • Orthographic Ambiguity: The system does not guarantee 100% classification accuracy. Certain handwritten characters possess identical visual geometries under 28x28 bounding box normalization (including 'L' vs '1', 'I' vs '1', '0' vs 'O', and 'f' vs 'F'). Classification outputs represent statistical maximum-likelihood estimates, not deterministic certainties.
  • No Critical System Use: This software is not certified for mission-critical, life-safety, financial, or automated legal document execution without human verification.
