Privacy Policy

Effective Date: October 11, 2026 | System Version: 1.0.0 (Localhost Deployment)

1. Overview and Scope

This Privacy Policy governs the processing of data within the LSTM Handwriting Recognition system running locally on your workstation. This software operates as an offline optical character recognition tool designed for research, benchmarking, and educational evaluation of recurrent neural architectures on the EMNIST Balanced dataset.

2. Data Collection and Local Processing

The system does not collect, transmit, or synchronize any personal data to external third-party servers. All operations occur exclusively on your local host environment (127.0.0.1):

  • Input Strokes and Canvas Data: Graphical character data drawn on the input canvas is transmitted strictly via internal HTTP requests to the local Python inference engine (localhost:8000/api/predict) for matrix transformation. No canvas data is permanently stored or broadcast over the public Internet.
  • Test Samples: Test evaluations utilize pre-cached local binary files from the National Institute of Standards and Technology (NIST) EMNIST archive stored in the local data directory.
  • Log Files and Metrics: Operational logs and evaluation matrices remain stored solely within your local file system under the project directory.

3. Cookies and Analytics

This application does not employ tracking cookies, persistent identifiers, advertising pixels, or third-party web analytics tools (such as Google Analytics or Segment). Web sessions run entirely in transient client-side memory.

4. Data Retention

Canvas drawings are processed in-memory and discarded upon execution or canvas reset. Stored artifacts consist exclusively of static model weights (lstm_handwriting_model.keras) and pre-computed evaluation reports generated during supervised evaluation.

5. Custom Domain and Network Configuration

When running this system behind a reverse proxy or mapped custom domain (e.g., ocr.internal or local DNS bindings), the network boundary is determined entirely by the host administrator. The software includes no external dependencies or external beacon telemetry.

6. Security

Because the service binds to the local loopback interface by default (127.0.0.1), network exposure is contained within the local machine unless the user explicitly configures binding to external network interfaces.

7. Contact and Administrative Information

For questions regarding this technical implementation or academic reproduction, please refer to the project repository documentation at PROJECT_REPORT.md and README.md.
